# Research materials

This folder is the place to add materials that are approved for redistribution:

- `assignment/` — official assignment instructions (only if redistribution is permitted).
- `reports/` — original technical and plain-language reports.
- `notebooks/` — original model notebook and reproducibility notes.

The current technical report, project explanation PDFs, user guide, and complete
analysis notebook are already kept in the repository's `reports/` and `notebooks/`
folders. The Methodology page links directly to those originals. Do not copy or
publish restricted course instructions without permission.
